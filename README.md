# Hán Tự Quán

Từ điển Trung–Việt dành cho người học chữ Hán. Ứng dụng hỗ trợ mẹo nhớ bằng hình ảnh, phân tích bộ thủ, hoạt ảnh thứ tự nét, luyện viết, nhận dạng chữ từ ảnh, sổ tay và ôn tập HSK.

Mã giao diện và dữ liệu học nằm trong `public/`. Thông tin nguồn và giấy phép dữ liệu có tại `public/data/sources.html`.
